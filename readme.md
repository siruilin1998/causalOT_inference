# causalOT_inference

Code and experiments for causal inference with optimal transport (OT), including scripts to reproduce figures and tables.

## Repository structure

- `causal_OT_for_FIGURE1/`  
  Code to reproduce Figure 1.

- `causal_OT_for_FIGURE2/`  
  Code to reproduce Figure 2.

- `causal_OT_for_FIG3TAB2/`  
  Code to reproduce Figure 3 / Table 2 (as named in the folder).

- `causal_OT_for_realdata/`  
  Real-data experiment pipeline.
